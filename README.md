  <h2>▶️ Getting Started</h2>
  <p>To run the app locally:</p>
  <ol>
    <li>
      <strong>Clone the repository:</strong>
      <pre><code>git clone https://github.com/sakshimuchhala1227/flask.git
cd flask</code></pre>
    </li>
    <li>
      <strong>Create a virtual environment (optional but recommended):</strong>
      <pre><code>python -m venv venv
source venv/bin/activate  # For Linux/Mac
venv\Scripts\activate     # For Windows</code></pre>
    </li>
    <li>
      <strong>Install dependencies:</strong>
      <pre><code>pip install Flask</code></pre>
    </li>
    <li>
      <strong>Run the Flask app:</strong>
      <pre><code>python app.py</code></pre>
    </li>
    <li>
      <strong>Open your browser and visit:</strong>
      <pre><code>http://localhost:5000/</code></pre>
    </li>
  </ol>
